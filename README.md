# MaliManager v2
نسخه توسعه‌یافته اپ مدیریت مالی فارسی.

امکانات: حساب عادی، حساب کالایی، تراکنش بدهکار/بستانکار، دریافت/پرداخت کالا، تاریخ شمسی، ویرایش و حذف، سود روزشمار سالانه، سود ماهانه با نرخ جداگانه برای هر ماه، محاسبه مجدد سود پس از اصلاح تراکنش‌های گذشته، مقصد سود، و بکاپ/بازیابی JSON از طریق Storage Access Framework (از جمله Google Drive).

## ساخت APK
پروژه Android Studio/Gradle است. پس از باز کردن پروژه، `assembleDebug` یا `assembleRelease` را اجرا کنید.

نکته: برای نسخه انتشار، signing key اختصاصی تنظیم کنید.

## v2.1 تغییرات
- نرخ سود ماهانه برای سال‌های مختلف قابل ثبت و ویرایش است.
- اصلاح/حذف تراکنش یا تنظیمات سود، سودهای خودکار همه حساب‌ها را مجدداً بازسازی می‌کند تا مقصد سود هم صحیح بماند.
- مانده حساب‌ها شامل سودهای واریزشده است.
